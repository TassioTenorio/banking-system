# 🏦 Banking System

A command-line banking application developed in Python to simulate essential banking operations and cash management.

The system provides account balance management, deposits, withdrawals, transaction history, and banknote inventory control, with validation mechanisms to ensure consistent transactions.

## 🚀 Features

- Account balance inquiry
- Cash withdrawals
- Cash deposits
- Transaction history
- Banknote inventory management
- Withdrawal validation based on available banknotes
- Input validation and exception handling
